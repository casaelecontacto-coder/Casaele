# Quick Start: "How to Use" Footer Page

## ✅ What's Been Done

1. **Footer Updated** - "How to use" link now points to `/page/how-to-use`
2. **Seed Script Created** - Automatically creates the CMS page with default content
3. **Production-Ready** - Fully editable from admin panel, matching your UI/UX

## 🚀 Setup (One-Time)

Run this command in your Backend directory:

```bash
npm run seed:how-to-use
```

**That's it!** The page is now live and accessible.

## 📍 Where to Find It

- **Frontend URL:** `http://localhost:5173/page/how-to-use`
- **Footer Link:** Click "How to Use" in the Support section
- **Admin Edit:** `/admin/cms` → Edit "How to Use Casa De ELE"

## ✏️ How to Edit

1. Login to admin panel (`/admin/login`)
2. Go to "CMS Pages" in sidebar
3. Find "How to Use Casa De ELE"
4. Click Edit button
5. Modify content, add images, or embed H5P content
6. Save changes
7. View on frontend immediately
